B1 — The Glacier cost gotcha

The current lifecycle policy moves sold listing photos to S3 Glacier Flexible Retrieval after 30 days.

S3 Glacier Flexible Retrieval has a minimum storage duration of 90 days. If an object is deleted after being archived for only 10 days, AWS charges for the remaining 80 days of the minimum storage period.

This creates unexpected early-deletion charges and can increase storage costs beyond the planned budget.

Redesign:

1. Delay archival until the application deletion-request window has expired.
2. If immediate deletion is required, keep the object in S3 Standard until it is safe to archive.
3. Implement lifecycle rules based on the actual retention policy.
4. Monitor storage costs and early-deletion charges using AWS Cost Explorer and billing alerts.

This approach protects the deletion requirement while avoiding unnecessary Glacier early-deletion charges.
